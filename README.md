# Product Preview Card - Perfume

Minha solução para o desafio **Product preview card component** do [Frontend Mentor](https://www.frontendmentor.io), feita com HTML e CSS. O cartão apresenta o perfume Gabrielle Essence Eau De Parfum, com imagem, descrição, preço promocional, preço original e o botão "Add to Cart".

![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)

## O que pratiquei

Estrutura da página com HTML, estilização e layout com CSS e a construção de um componente a partir de um design de referência.

## Como visualizar

```bash
git clone https://github.com/GustavoBs12/Perfume.git
```

Depois, abra o arquivo `index.html` no navegador.

## Sobre o desafio

O design e as imagens vêm do desafio do Frontend Mentor. Este repositório contém apenas a minha implementação.
